# LifeOS

**LifeOS** is a production-ready Progressive Web App — a personal execution system that combines task management, habit tracking, focus sessions, accountability, streaks, debt carry-forward, and performance analytics.

Built for people who need to consistently ship on:

- Job applications
- DSA / LeetCode
- Open source contributions
- AI projects
- Networking
- Fitness
- Learning

## Features (all phases)

### Phase 1 — Auth + Daily Dashboard + Tasks
- Clerk authentication with webhook user sync
- Auto-generated `Day` records with Kanban board (Todo / In Progress / Completed / Skipped)
- Drag-and-drop via DnD Kit with optimistic updates
- Task templates (Work Day, Weekend, Custom) auto-populate each morning
- Quantitative tasks with +/- counters (e.g. 20 job applications)

### Phase 2 — Focus Sessions + Alarm
- Pomodoro and custom duration focus sessions
- Mandatory looping Web Audio alarm with full-screen modal
- End Session / Continue Session / Snooze 5 Minutes actions

### Phase 3 — Streaks + Debt
- LeetCode-style streak tracking (60% daily threshold)
- GitHub-style completion heatmap
- Debt system: unfinished quantitative work rolls into the next day

### Phase 4 — Analytics + Weekly Planning
- Daily / weekly / monthly completion charts
- Focus hours, debt trends, category breakdown
- Top 3 weekly goals with progress bars (Sunday planning)

### Phase 5 — Gamification
- XP per task category with level progression
- Achievement system with unlock tracking

### Phase 6 — Builder Modes
- **Job Search** — applications, interviews, offer rate
- **Open Source** — issues, PRs, merges, commits
- **AI Builder** — research, agents, experiments, project hours

### PWA
- Installable on desktop, Android, and iOS
- Service worker with offline caching (production builds)
- Push notification subscription (VAPID)

### Dark Mode
- Light / dark / system via `next-themes`, persisted in settings

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm (`npm i -g pnpm`)
- A [Neon](https://neon.tech) PostgreSQL database
- A [Clerk](https://clerk.com) application

### 1. Clone & install

```bash
pnpm install
```

### 2. Environment variables

Copy `.env.example` to `.env.local` and fill in:

```bash
cp .env.example .env.local
```

| Variable | Description |
|----------|-------------|
| `DATABASE_URL` | Neon **pooled** connection string |
| `DIRECT_URL` | Neon **direct** connection string (migrations) |
| `NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY` | Clerk publishable key |
| `CLERK_SECRET_KEY` | Clerk secret key |
| `CLERK_WEBHOOK_SIGNING_SECRET` | Clerk webhook signing secret |
| `NEXT_PUBLIC_APP_URL` | App URL (`http://localhost:3000` locally) |
| `NEXT_PUBLIC_VAPID_PUBLIC_KEY` | Web Push public key (optional) |
| `VAPID_PRIVATE_KEY` | Web Push private key (optional) |

Generate VAPID keys:

```bash
npx web-push generate-vapid-keys
```

### 3. Database setup

```bash
# Apply migrations (production)
pnpm db:deploy

# Or push schema directly (development)
pnpm db:push

# Seed demo data (optional)
pnpm db:seed
```

### 4. Clerk webhook (production)

In the Clerk Dashboard → Webhooks, add:

- **URL:** `https://your-domain.com/api/webhooks/clerk`
- **Events:** `user.created`, `user.updated`, `user.deleted`

### 5. Generate PWA icons (optional)

```bash
node scripts/generate-icons.mjs
```

### 6. Run locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel + Neon

### Neon

1. Create a project at [neon.tech](https://neon.tech)
2. Copy the **pooled** connection string → `DATABASE_URL`
3. Copy the **direct** connection string → `DIRECT_URL`

### Vercel

1. Import the repository at [vercel.com](https://vercel.com)
2. Set all environment variables from `.env.example`
3. Set `NEXT_PUBLIC_APP_URL` to your production URL
4. Build command: `pnpm build` (runs `prisma generate && next build`)
5. After first deploy, run migrations against Neon:

```bash
DATABASE_URL="..." DIRECT_URL="..." pnpm db:deploy
```

Or add a Vercel build step:

```json
"build": "prisma migrate deploy && prisma generate && next build"
```

### Clerk production

1. Add your Vercel domain to Clerk allowed origins
2. Update redirect URLs to `https://your-domain.com/dashboard`
3. Configure the webhook endpoint

### PWA install

- **Desktop:** Chrome → address bar install icon
- **Android:** Chrome → "Add to Home screen"
- **iOS:** Safari → Share → "Add to Home Screen"

## Architecture Notes

- **Server Actions** handle mutations with Zod validation and `revalidatePath`
- **Repository pattern** in `src/server/repositories/` for typed data access
- **Services** encapsulate business rules (debt carry-forward, streak recompute, XP)
- **Zustand** for client UI state (Kanban dialog, focus timer, alarm)
- **React Query** provider ready for future client-side caching
- **Bootstrap** (`src/lib/bootstrap.ts`) provisions Work Day + Weekend templates on first sign-in
